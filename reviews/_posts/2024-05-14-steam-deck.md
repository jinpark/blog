> **TL;DR**
> 
> Get the Steam Deck if you don't have or want a gaming computer but want to play indie PC games or emulated games.

---

The Valve Steam Deck is a handheld linux gaming computer made by Valve, the owners of Steam. The hardware is a bit dated (as of 2024) but can still play the majority of games created before 2022. AAA games will probably perform better when the graphics performance is not set to the highest spec. The ergonomics is good for playing most types of games, the portability is good but a bit heavy compared to the nintendo switch, the software and UI is very good and the overall experience is great.

Valve did the monumental task of creating an compatibility layer on linux to be able to run Windows games. The base of Steam OS is Arch Linux. Steam OS gives a console like experience to play PC games on. You can drop down to actual Arch Linux and install whatever packages you want. Theres already a big community of users so a lot of issues are reported pretty quickly. There is also a good diy scene for it as well if anything goes wrong.

If your main computer is a Macbook, especially the newer arm based macs, having a Steam Deck allows you to play pretty much any PC game you want portably since the M processors don't let you run windows x86 to play games.

Theres also a Steam Deck OLED which is a slightly upgraded version of the steam deck. The SOC (system on a chip) is slightly improved, the screen is better and slightly bigger, and the battery is better. The OLED version starts with the 512gb model which is a $150 USD over the base 256gb version at $400 USD. If you can afford it, I suggest getting the OLED version, or look into getting a refurbished model.
